# Rich UI (React)

This app builds a single-file HTML widget for ChatGPT.

Build steps:
1. `npm install`
2. `npm run build`

Output:
- `custom_version/Assets/rich/formulaire.html`

Environment:
- `VITE_MCP_URL` can be set in `.env` for local dev use.
- In React, read it with `import.meta.env.VITE_MCP_URL`.
